# The approved prototype (reference only)

`gen.py` is the script that wrote the screens of the panel prototype approved on 2026-11-10. It is kept here as the visual and wording reference for the side panel: each `s_…` function is one screen, each `o_…` function one sheet. All data in it is invented. It is not part of the build and is never run by it.

`build-brief.md` is the brief written with the prototype. Three decisions were open on the page and were picked: a private note under the line in the diff (built last, step 4); Post publishes straight away after a preview (step 3); a review starts on a click.
